# 《增删卜易》修复实验账本

- 目标：在独立分支修复审查确认的主要算法偏差，并增加可追溯、可选择、不过度断定的解卦辅助信息。
- 分支：`feat/zengshan-analysis-experiment`
- 范围：
  - 修复变卦六亲、暗动/日破、特殊三合条件。
  - 补充用神—元神—忌神—仇神、进退神、完整动化关系、化空破墓绝、反吟伏吟、特殊卦变和应期线索。
  - 扩展 API 响应模型，优化六爻表格及解卦辅助区排版。
  - 增加原典规则编号、触发事实和原文来源，形成可追溯依据。
- 已确认事实：
  - 当前排盘主链为 `api.paipan → LiuyaoEngine.paipan → _build_yao_data → ShengKeCalculator`。
  - 当前变卦六亲直接读取变卦所属宫的预计算六亲，违反“变出之爻安六亲者仍照正卦而推”。
  - 当前暗动只看月建是否同类或生扶，漏判原典“寅月己未日丑土暗动”。
  - 当前内外卦特殊三合只要求一个边爻发动，已有测试固化该错误口径。
  - 当前前端状态列采用互斥优先级，丢失可同时成立的日月原始关系。
- 决策：
  - 数据分为“排盘原始事实、规则触发结果、选定用神后的辅助线索”三层。
  - 所有新增断卦信息均返回规则编号、实际触发依据和原典章节；不自动输出吉凶终局。
  - 应期只输出地支和触发条件候选，不伪造具体日期；远近仍须结合占问语境。
  - 用神由用户选择，后端预计算五种六亲取用方案，前端只切换展示，不重复请求。
  - 兼容现有字段；新增字段采用加法扩展，原有客户端仍可读取旧结构。
  - 主表采用七列快速看盘：状态格承载世应、动静、日月，变卦格承载变爻日月，关系列独立承载动化关系。
  - 用神选择器固定在排盘结果右上角；主爻统一上方对齐，四神、状态、变爻日月与动化关系统一放在下方信息轨道。
  - 视觉密度以主分支卦盘为基准：恢复世应底色与紧凑行高，状态和动化改为横排纯文本，不给选择器增加额外容器外框。
- 修改文件：
  - `backend/core/liuyao_engine.py`：修正变卦六亲，接入动化与解释层。
  - `backend/core/shengke.py`：保留完整日月事实，修正暗动、日破和特殊三合条件。
  - `backend/core/interpretation.py`：新增四神、作用链、飞伏、动化、反伏吟、特殊卦变、应期及规则注册表。
  - `backend/models/gua.py`：为上述信息增加严格响应模型。
  - `frontend/index.html`、`frontend/css/style.css`、`frontend/js/paipan.js`：增加分区、响应式展示和用神交互。
  - `tests/test_shengke.py`、`tests/test_interpretation.py`：增加原典案例与新增契约回归。
- 验证结果：
  - 全量 `pytest` 通过，共 63 项。
  - `ruff check backend tests`、前端脚本语法检查和 `git diff --check` 通过。
  - 浏览器实测五种用神均可切换；桌面为双列、窄屏为单列，页面无横向溢出，排盘表按设计独立横向滚动。
  - 浏览器实测主表表头与六行均为七列；状态、变卦、关系各归其位，空日月关系不生成“—”；五种取用均生成四神标记且可覆盖伏神。
  - 桌面端选择器位于干支右侧；500px 窄屏端位于干支下方顶部整行，页面无整体横向溢出，只有主表容器按设计横向滚动。
  - 桌面实测六行本卦、变卦主爻顶部偏移均为 9px，四神及各类状态顶部偏移统一为 34px；仅用神候选行整行适度高亮。
  - 规则依据共 12 条且均带来源链接；上方依据编号可展开并定位闪烁对应规则，伏神用神可显示飞伏关系和出伏候选。
- 剩余风险：
  - 用神取舍、旺衰权重、两现取舍和应期远近依赖占问类别，实验版只提供条件化事实与候选。
  - 旺空、动空、墓绝是否最终有效仍需结合占事与时序，未输出单一吉凶分数。
  - 古籍转录存在少量异体字和标点差异；规则按审查报告已交叉核验的明确条文实现。
- 下一步：完成本轮回归、提交并推送实验分支，等待真实占例反馈后再校准旺衰权重与应期远近。
