# 《增删卜易》修复实验账本

- 目标：在独立分支修复审查确认的主要算法偏差，并增加可追溯、可选择、不过度断定的解卦辅助信息。
- 分支：`feat/zengshan-analysis-experiment`
- 范围：
  - 修复变卦六亲、暗动/日破、特殊三合条件。
  - 补充用神—元神—忌神—仇神、进退神、完整动化关系、化空破墓绝、反吟伏吟、特殊卦变和应期线索。
  - 扩展 API 响应模型，优化六爻表格及解卦辅助区排版。
  - 增加原典规则编号、触发事实和原文来源，形成可追溯依据。
- 已确认事实：
  - 当前排盘主链为 `api.paipan → LiuyaoEngine.paipan → _build_yao_data → ShengKeCalculator`。
  - 当前变卦六亲直接读取变卦所属宫的预计算六亲，违反“变出之爻安六亲者仍照正卦而推”。
  - 当前暗动只看月建是否同类或生扶，漏判原典“寅月己未日丑土暗动”。
  - 当前内外卦特殊三合只要求一个边爻发动，已有测试固化该错误口径。
  - 当前前端状态列采用互斥优先级，丢失可同时成立的日月原始关系。
- 决策：
  - 数据分为“排盘原始事实、规则触发结果、选定用神后的辅助线索”三层。
  - 所有新增断卦信息均返回规则编号、实际触发依据和原典章节；不自动输出吉凶终局。
  - 应期只输出地支和触发条件候选，不伪造具体日期；远近仍须结合占问语境。
  - 用神由用户选择，后端预计算五种六亲取用方案，前端只切换展示，不重复请求。
  - 兼容现有字段；新增字段采用加法扩展，原有客户端仍可读取旧结构。

- 剩余风险：
  - 用神取舍、旺衰权重和应期远近依赖占问类别，实验版只提供规则事实与候选。
  - 古籍转录存在少量异体字和标点差异；规则按审查报告已交叉核验的明确条文实现。
