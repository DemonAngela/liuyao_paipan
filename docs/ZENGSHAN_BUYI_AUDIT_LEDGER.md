# 《增删卜易》算法核对账本

- 目标：核对项目“爻位、六神、伏神、本卦、状态、变卦、关系”等排盘算法与判断是否符合《增删卜易》。
- 范围：排盘核心、卦表数据、日月旺衰与动变关系、接口模型、前端展示、相关测试，以及利于解卦的算法和信息建议；不扩展到断卦辞生成。
- 已确认事实：
  - 排盘入口为 `backend/api/paipan.py`，核心调用 `backend/core/liuyao_engine.py::LiuyaoEngine.paipan`。
  - 本卦按六爻阴阳值查表，动爻逐位阴阳反转生成变卦。
  - 六神按日干生成；伏神从本宫首卦同爻位补齐本卦缺失六亲。
  - 64 卦卦名、阴阳爻、纳甲、六亲、世应、宫属，以及六神、伏神的基础排布与原典规则一致。
  - 变卦六亲错误地按变卦所属宫计算；原典要求仍按本卦宫五行推六亲。
  - 静爻受日冲的“暗动/日破”判定过窄，无法复现原典“寅月己未日丑土暗动”的明确例证。
  - 内外卦特殊三合分支只要求一个边爻发动，会把另一完全静止边爻错误计入成局。
  - 当前“状态、关系”主要是事实标签，尚未完整实现日月动变对静爻、变爻、飞伏神的作用链与旺衰有效性判断。
- 决策：
  - 以用户保存的中华文库正文为第一核对基准；仅在明显转录歧义处用同书其他版本交叉校正。
  - 将“古籍明确规定的排盘规则”与“项目自行扩展的提示性标签”分开评价。
  - 建议后续以“原始事实—规则结论—解释依据”三层模型承载解卦信息，避免展示层标签覆盖或丢失事实。
- 修改文件：
  - `docs/ZENGSHAN_BUYI_AUDIT.md`
  - `docs/ZENGSHAN_BUYI_AUDIT_LEDGER.md`
- 验证结果：
  - 独立校验 64 卦、384 个爻位/阴阳/纳支/六亲/世应宫属均无差异。
  - 十天干六神、8 个六合卦、10 个六冲卦均与原典一致。
  - 穷举 4,032 种本变组合，12,288 个实际变出爻中有 9,864 个六亲不符合“仍照正卦而推”。
  - 原典暗动例证被项目判为日破；项目现有三合测试确认固化了静爻误成局行为。
  - 聚焦测试 `test_najia.py`、`test_engine_regression.py`、`test_shengke.py`、`test_ganzhi.py`、`test_meihua.py` 共 27 项通过，说明上述偏差尚未被现有回归测试覆盖。
- 剩余风险：正文存在少量古籍转录/OCR 歧义；用神选取、应期和具体断语高度依赖占问语境，未将流派性判断伪装为确定算法。
- 下一步：审查已完成；如进入修复，优先修正变卦六亲、暗动/日破和三合条件，再建设统一作用关系与旺衰有效性模型。
