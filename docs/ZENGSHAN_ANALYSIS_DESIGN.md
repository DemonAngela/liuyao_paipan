# 《增删卜易》解卦辅助实验设计

## 1. 设计边界

本实验只把原典中可由排盘事实确定的规则结构化，不代替占问语境决定用神，不把应期候选包装为确定日期，也不以六神或单一标签直接判定吉凶。

## 2. 数据分层

1. **原始事实层**：本变爻、日月生克冲合、旬空、月破、动静、飞伏信息。
2. **规则结论层**：进退神、回头生克、化合冲、化空破墓绝、反吟伏吟和特殊卦变。
3. **取用辅助层**：用户选定六亲后，展示用神、元神、忌神、仇神候选及应期地支线索。

每项规则结论必须包含稳定规则编号、触发爻位、事实说明、原典章节和来源链接。

## 3. 主要规则

| 功能 | 实现口径 | 边界 |
|---|---|---|
| 变卦六亲 | 变支五行仍以本卦宫五行推六亲 | 不读取变卦所属宫六亲 |
| 暗动/日破 | 静爻日冲，非月破且受月建生扶、同类，或日冲同五行者为暗动；否则为日破 | 同时保留“日冲”等原始事实 |
| 三合 | 三个本支成局至少两爻发动；初三或四六动化成局时两边爻均须发动 | 暗动视为发动，变支只来自实际明动爻 |
| 四神体系 | 元神生用神，忌神克用神，仇神克元神且生忌神 | 用神由用户选择，不自动代选 |
| 用神作用链 | 明动、暗动及受日月扶而无空破的静爻，按生、克、比扶、合、冲列出对所选用神的作用候选 | 变爻不跨位作用；效力仍须核空破墓绝与旺衰 |
| 飞伏 | 伏神同时展示日月关系、飞神生克和飞神空破，并列逢值、冲飞、填冲候选 | 不直接判伏神必然有用；保留原典“必要时再占”提示 |
| 进退神 | 按原典七组进神和七组退神逐爻比对本支与变支 | 只对明动且有变支的爻成立 |
| 动化关系 | 同时保留回头生克、化合冲、进退、化空破墓绝等全部事实 | 不采用互斥优先级覆盖其他关系 |
| 反吟伏吟 | 按内卦、外卦分别识别卦体反吟；动变后区域纳支不变识别伏吟；爻支化冲标明爻反吟 | 未发动区域不判伏吟 |
| 特殊卦变 | 展示本卦与变卦的六冲、六合、游魂、归魂及其转换；八纯卦间补充卦体五行回头关系 | 不脱离用神直接判吉凶 |
| 应期 | 静待值冲、动待值合、空待填冲、破待填合、合待冲开、进退神按原典列候选地支 | 只输出候选地支和规则依据 |

## 4. API 扩展

- 爻数据新增完整的 `day_relations`、`month_relations` 和 `transformation_relations`。
- 变爻数据新增日月关系，便于核对化破等事实。
- 排盘结果新增 `analysis`：
  - `transformation_findings`
  - `structure_findings`
  - `yongshen_profiles`（含四神候选、`action_findings` 与应期）
  - `rule_traces`
  - `notice`

扩展字段保持旧字段不变，`shengke` 继续作为动化关系的兼容文本。

## 5. 展示设计

- 六爻主表收敛为“爻位、六神、伏神、本卦、变卦”五列；日月、世应、动静归入本卦，变爻日月与动化关系归入变卦。
- 表格外保留横向滚动容器，窄屏不压缩卦爻信息。
- 用神选择器放在排盘结果右上角，窄屏自动换为顶部整行，确保先取用再看盘。
- 四神以紧贴本卦六亲或伏神的低饱和小标签实时标记，短暂微动效提示更新，不再使用高亮整行。
- 卦内日月、世应、动静及动化信息采用紧凑横排文本，仅四神保留小标签，避免形成“标签墙”。
- 四神候选仍采用响应式卡片网格；作用链、动变、卦体、应期作为详细依据分区展示。
- 规则原文依据默认折叠，需要核对时再展开，减少主视图拥挤。

## 6. 验收重点

- 原典“水天需变天水讼”变卦栏六亲和“寅月己未日丑土暗动”成为固定回归。
- 穷举所有本卦和动爻组合验证变卦六亲均按本宫推导。
- 错误的单边发动三合测试改为“不成局”，双边发动新增正例。
- 五种用神方案、作用链、飞伏生克、进退神、动化多标签、反伏吟和应期候选均有聚焦测试。
- API 严格模型验证、前端脚本语法和桌面/窄屏布局完成验收。
