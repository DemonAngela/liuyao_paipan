# Contributing

Thank you for contributing to liuyao_paipan.

## Development workflow

1. Create a branch from `main`.
2. Add tests for algorithm changes.
3. Keep API behavior backward compatible when possible.
4. Submit a pull request with a clear description.

## Areas needing contribution

- Calendar and Ganzhi validation against authoritative references.
- Regression tests for the 64 hexagrams and changing lines.
- API input validation improvements.
- Documentation improvements.

## Code quality

Please avoid changing traditional rule implementations without adding test cases or explaining the reference source.
