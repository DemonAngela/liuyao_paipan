# Code of Conduct

## Our standard

This project welcomes constructive participation from people with different technical backgrounds and interpretations of traditional source material.

Contributors should:

- discuss code, evidence, and reproducible behavior rather than personal attributes;
- provide sources and test cases when proposing changes to calendrical or Liuyao rules;
- keep reviews specific, technical, and actionable;
- respect differing interpretations when the underlying tradition is not uniform;
- avoid harassment, threats, discriminatory language, spam, or deliberate disruption.

## Maintainer responsibility

The maintainer may edit or remove comments, issues, pull requests, or other contributions that violate this standard. Repeated or severe violations may result in participation restrictions.

## Reporting

For ordinary conduct concerns, open a private contact with the maintainer through the GitHub profile. Security vulnerabilities should follow `SECURITY.md` rather than public issue discussion.
